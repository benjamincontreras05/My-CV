# GOLDTY — Virtual Agenda & Productivity Platform

## The Problem

Physical agendas are often inefficient, frustrating, and prone to losing track of critical events. Students lacked a centralized digital tool to classify priorities and optimize their study routines.

## Process & Engineering Challenges

Developed in a dynamic team environment. We faced major communication bottlenecks, design discrepancies, and code conflicts. We successfully resolved these through assertive mediation, establishing clear UI patterns, and conducting rigorous AI-assisted code reviews.

## The Solution

An interactive web platform based on time-management matrices that separates urgent, important, and non-important tasks. It integrates performance tools like the Pomodoro technique to maximize student focus.

tech_stack: [HTML5, CSS3, JavaScript, Node.js, Supabase]
